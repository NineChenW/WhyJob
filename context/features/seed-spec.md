# Seed Data Specification

## Overview

Create a seed script (`prisma/seed.ts`) to populate the database with sample data for development and demos.

## Requirements

- Based on the the database schema(`prisma/schema.prisma`) and the mock data(`src/lib/mock-data.ts`)
- With test cases to ensure the script suit with the database schema
